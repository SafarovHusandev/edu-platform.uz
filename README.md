# Edu-Platform.uz

Zamonaviy ta'lim platformasi frontend qismi (Next.js, TailwindCSS).

## Loyihani ishga tushirish (Development mode)

1. Kerakli paketlarni o'rnatish (agar o'rnatilmagan bo'lsa):
```bash
npm install
```

2. Development serverni yoqish:
```bash
npm run dev
```

3. Brauzerda ochish:
[http://localhost:3000](http://localhost:3000)

## Production build

```bash
npm run build
npm run start
```
